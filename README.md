# Диктовка: голос → локальная LLM → чистый текст

Говоришь по горячей клавише, и текст появляется там, где стоит курсор, уже без «ну, короче», с самоисправлениями («в среду, нет, в четверг»), пунктуацией и живым синтаксисом. Распознавание и правка идут на самом маке, текст в сеть не уходит.

```
FluidVoice (Parakeet, распознавание на маке)
   │  POST /v1/chat/completions, модель pravka | korotche | komanda
   ▼
proksi.py :1235  ── подставляет инструкцию, отключает рассуждения ──►  LM Studio :1234 (Gemma 4 12B)
```

## Стек

Python 3 без зависимостей, LM Studio как локальный OpenAI-совместимый сервер, Gemma 4 12B (QAT), FluidVoice как клиент диктовки.

## Режимы (виртуальные модели прокси)

| Модель | Что делает | Инструкция |
|---|---|---|
| `pravka` | чистовая правка надиктованного: паразиты, самоисправления, пунктуация, живой синтаксис | `prompt-pravka.txt` |
| `korotche` | сокращает текст примерно вдвое, не теряя фактов | `prompt-korotche.txt` |
| `komanda` | голосовая команда над выделенным текстом: инструкция клиента сохраняется, к ней дописываются правила языка | `prompt-stil.txt` |

Инструкции — обычные текстовые файлы, правятся без перезапуска. Любая другая модель проходит через прокси насквозь.

## Как устроено

- `proksi.py` подменяет виртуальную модель на настоящую и подставляет системную инструкцию.
- Рассуждения модели отключаются (`reasoning_effort: none`), иначе Gemma думает 15 с над одной фразой.
- Если модели не хватает памяти, прокси выгружает всё из LM Studio и повторяет запрос.
- Каждый запрос пишется в `zhurnal.jsonl` (в репозиторий не входит): по нему видно, что именно прислал клиент.
- `test.py` прогоняет три тестовые диктовки через выбранную модель и инструкцию и печатает время каждой.

Замер на MacBook с M5 и 16 ГБ: Gemma 4 12B правит фразу за 4 с в прогретом состоянии и за 21 с с загрузкой модели. Модель 4B быстрее (3–5 с), но путает самоисправления и подменяет слова, поэтому не используется.

## Запуск

```bash
lms server start                     # LM Studio, модель google/gemma-4-12b-qat
python3 proksi.py                    # прокси на localhost:1235
python3 test.py google/gemma-4-12b-qat prompt-pravka.txt
```

В FluidVoice добавить провайдера Custom (OpenAI-compatible): Base URL `http://localhost:1235/v1`, ключ любой, модель `pravka`. Для автозапуска подходит launchd-агент, который вызывает `zapusk.sh`.
